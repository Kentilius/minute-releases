# Minute — installateurs

Ce dépôt ne contient que les installateurs de l'application **Minute** et le fichier `latest.json` que l'application lit pour proposer ses mises à jour. Aucun code source n'est publié ici.

- Dernière version : voir l'onglet « Releases ».
- Windows : `Minute_<version>_x64-setup.exe` (installation pour l'utilisateur courant).
- macOS (Apple silicon) : `Minute_<version>_aarch64.dmg`.

Les paquets de mise à jour sont signés ; l'application n'accepte que ceux signés avec la clé qu'elle connaît.
